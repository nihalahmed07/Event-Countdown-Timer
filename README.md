# ⏳ Event Countdown Timer (TypeScript)

A simple countdown timer built using TypeScript.

## Features
- Set a target date and time
- Live countdown in days, hours, minutes, and seconds
- Pause, resume, and reset functions

## How to Run
1. Clone this repo:
   ```bash
   git clone https://github.com/yourusername/event-countdown.git
   cd event-countdown
    ```
   
2. Install TypeScript if you don't have it:
    ```bash
    npm install -g typescript
    ```
3. Compile:
   ```bash
   npm install -g typescript
   ```

4. Open index.html in your browser.
